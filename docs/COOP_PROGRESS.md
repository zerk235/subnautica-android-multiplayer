# Капсула, двери и прогресс гостя

Проверки ниже начались на протоколе 40. Для совместной проверки установите
одинаковую версию мода на оба телефона с Subnautica 1.22.83315 и откройте
отдельный тестовый мир.

- Почините стартовую капсулу по очереди с каждого телефона в свежих мирах.
  У напарника должно обновиться состояние ремонта, а после полного ремонта
  должны погаснуть эффекты повреждения и включиться обычное освещение.
- Почините встроенное радио. Оно должно стать исправным у напарника. Ночью
  зайдите в капсулу и выйдите обратно. Удалённый аватар должен использовать
  освещение капсулы внутри и уличное освещение после выхода.
- Переложите ресурс из инвентаря гостя в ящик капсулы. Заберите его хостом,
  затем повторите в обратную сторону. Предмет должен перейти один раз, даже
  если оба игрока одновременно пытаются его забрать.
- Откройте и закройте дверь обломков. Для двери под резак проверьте также полный
  разрез. Повторите с гостя и после повторной подгрузки комнаты.
- Пусть каждый игрок откроет по отдельному чертежу. Готовый рецепт должен
  появиться у напарника. Промежуточные этапы сканирования у каждого свои.
- Положите гостю отличающийся набор предметов и инструмент с частично
  разряженной батареей. Нажмите «Сохранить» гостем, затем сохранитесь хостом.
  После повторного подключения должны вернуться вещи, заряд, слоты быстрого
  доступа и записи КПК гостя внутри обновлённого мира хоста.

Для гостя контрольная точка записывается после успешного ручного сохранения.
Дождитесь окончания переноса через общий ящик перед сохранением. Повторный
вход использует сохранение этой же пары «телефон гостя и мир». Аварийное
закрытие до сохранения теряет изменения после последней контрольной точки.
Физика грави-ловушки и передача заряда при выбрасывании инструмента в мир
остаются отдельными игровыми сценариями.


## Первые 15 минут кооператива

Запустите одинаковую сборку на двух телефонах. Считайте время с момента, когда
гость получил управление. Начните со свежего мира и поменяйте роли во втором
прогоне. Порядок проверок учитывает, насколько ошибка мешает развитию.

| Время | Что делают игроки | Что должны увидеть оба |
| --- | --- | --- |
| 0–3 мин | Встречаются в капсуле, проверяют огнетушитель, аптечку, ящик и выход через люк. При наличии ремонтника чинят капсулу и радио. | Общая капсула и состояние ремонта. Одна аптечка или вещь из ящика уходит только одному игроку. |
| 3–8 мин | По очереди разбивают известняк, собирают кварц и металлолом, ловят рыбу, роняют и подбирают ресурс. Подплывают к одному сталкеру. | Один и тот же кусок породы даёт один ресурс. Подбор убирает объект у напарника. Один укус отнимает здоровье только у выбранного игрока. |
| 8–12 мин | Кладут ресурсы в общий ящик, крафтят сканер или ремонтник, открывают один рецепт по ходу игры. Если хватает материалов, крафтят глайдер. | Ресурс не дублируется. Готовый чертёж появляется у напарника. Изготовитель расходует вещи из инвентаря того, кто крафтит. |
| 12–15 мин | Сохраняются, гость выходит и подключается снова. Если открыт строитель, ставят отсек и люк. Для гарантированного теста стройки используйте отдельный мир с открытым строителем. | Возвращаются вещи гостя и чертёж. Оба видят отсек и могут войти через люк. |

Для нового игрока после входа самые заметные блокеры — разные ресурсы из
одного обломка, дубли аптечки и пропажа инструмента при переподключении.
Проверка разбиваемых обломков включает выпадение и исчезновение ресурса с обеих
сторон, даже когда оба игрока бьют одновременно. Синхронизация выбрасывания
предметов уже есть для части ресурсов. Разбивание обломков надо проверять отдельно.

Для первой базы приоритет у связки **отсек → люк → солнечная панель → шкаф →
изготовитель**. Постройка этих объектов уже проверялась. Следующая проверка
должна показать, что панель питает изготовитель у обоих и оба сохраняют доступ
к содержимому шкафа. Из новых объектов следующий кандидат — **настенный шкаф**
для тесной базы, затем **зарядное устройство для батарей** с учётом общей
энергии и сохранения заряда.

## Сталкер в тестовой сборке с протоколом 41

Оба игрока подплывают к одному сталкеру в лесу водорослей. Сначала ближе
держится хост, потом гость. Проверьте движение, анимацию укуса на обоих
экранах и изменение здоровья только у цели. Повторите с гостем за стеной
или внутри капсулы и после короткого обрыва связи. Для входа в эту сборку
на обоих телефонах нужна одинаковая версия мода.
