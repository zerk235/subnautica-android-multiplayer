# Проверки установщика

## Обновление APK 0.2 от 4 ноября 2026: сохранённые детали базы

Сборка мода `27c5ba3704129731af899a09e9069848f9f5633a`, протокол 23.
SHA256 APK установщика: `5d072c2a630df3f9d38f06d310439ec2f2c72561d7d9bcf2cbef3ab398811747`.
Исходники: коммит `ae70be5d385072629e956e5eee1a99b9f568f23e`.

- На обоих телефонах прошли test_single_cell_removal, test_structural_face_apply,
  test_ladder и test_build_completion. Добавлены случаи пустого реестра после
  загрузки, проверки нативного объекта и разрешения демонтажа, повторного
  удаления и защиты новой детали от запоздалого события удаления старой.
- В игре на госте подтверждены `verified=1` для удаления сохранённых люка
  и стеклянного отсека, затем новых люка, прямого и углового стеклянных отсеков.
  За следующие две минуты удалённые отсеки не применялись повторно.
  Владелец подтвердил правильный вид на телефонах.
- На рут-телефоне базовый игровой APK подготовлен локальным ключом установщика
  и обновлён с тем же сертификатом; ресурсный split и SHA256 всех 26 файлов
  миров сохранены. На нон-руте использовался прежний совместимый сертификат
  и ADB: после обычного adb install -r ресурсный split пришлось вернуть из
  исходного проверенного APK. Все 64 файла миров и исходный ресурсный split
  сверены по SHA256, профиль User 11 сохранён. Этот способ ADB не является
  проверкой режима наследования самого установщика на нон-руте.
- Подпись APK установщика и выравнивание библиотек на 16 КиБ проверены.
  В APK нет instrumentation, тестовых классов, игровых APK и ключей подписи.

Отдельное наблюдение: при расширении сетки базы размещение нового стеклянного
отсека может сообщать `target_cell=0 verified=0`. Внешний вид подтверждён
владельцем, последующий точный демонтаж прошёл с `verified=1`; чтение координат
после изменения anchor требует отдельной проверки. Все типы сохранённых деталей
в игровом тесте не перебирались. Полный непрерывный сценарий смены подписи
APK+миры версии 0.2 без ADB остаётся непроверенным.

## Исходный APK 0.2.0-preview: копии миров, Shizuku и профили

Нативная игровая библиотека осталась той же: `4e8e3ce0017891bf1549aa94272dc0142d0da6aa`.

- На обоих телефонах прошли проверки ZIP-копии, вложенных и скрытых файлов,
  SHA256, сохранения прежней папки при восстановлении, отказа на повреждённом
  архиве, выходе пути за папку и символических ссылках. Проверены импорт и
  сохранение последней исправной копии при неудачном импорте.
- Полная копия настоящего SavedGames через Shizuku проверена на руте: 26 файлов,
  4 013 901 байт, служба UID 0. На GT8 без root: 64 файла, 8 702 997 байт,
  служба UID 2000 (ADB). SHA256 и состав архива совпали с текущими сохранениями.
- На GT8 пользователь самостоятельно удалил основную игру при проверке патчера.
  Установка нового сертификата была отвергнута Android: старая копия пакета
  оставалась в профиле User 11. Этот профиль не удалялся и его данные не менялись.
- Для восстановления тестового телефона существующая игра была снова включена
  для User 0 через ADB `install-existing`. Затем новый установщик восстановил
  64 файла из своего ZIP через Shizuku UID 2000. Независимая проверка по ADB
  подтвердила SHA256 всех 64 файлов. Прежняя папка при повторном восстановлении
  сохранилась отдельно. Игра запустилась до главного меню; набор файлов остался.
  В меню «Играть» появились восстановленные миры с датами и превью.
  Этот ремонт профиля через ADB не является проверкой чистой установки APK
  новым ключом без компьютера на GT8.
- В код добавлена блокировка удаления при установленном пакете другого профиля.
  Синтетические случаи одного/нескольких профилей прошли. На настоящем GT8
  служба обнаружила User 11 и вернула отказ до удаления игры. Добавлена проверка
  сохранившегося пакета при отсутствии игры в основном профиле.
- Повторно прошли базовые проверки упаковки, Android Keystore и подписи APK
  на обоих телефонах с подключёнными зависимостями Shizuku API.
- На GT8 V17.0.0 устранён ограниченный доступ ADB: проверка локального кода
  Settings подтвердила скрытие нужного пункта при русском языке. Владелец выбрал
  English, включил Disable system optimization и предоставил доступ Shizuku.
  После этого проверка копирования через UID 2000 прошла. Помощь добавлена
  в интерфейс установщика и INSTALLER_BACKUPS.md. Открытие справки и текст
  обхода для GT8 проверены в установленной сборке 0.2.

На момент исходной сборки не проверены: чистая смена сертификата и установка самой игры на GT8 без ADB
восстановления профиля; обновление настоящей игры локальным ключом установщика;
принудительное заполнение накопителя и все прошивки. Приватные данные приложения
вне SavedGames не входят в архив. Первое подтверждение установки и вся миграция
APK+миров одним непрерывным сценарием версии 0.2 отдельно ещё не пройдены.

## 0.1.0-preview: исходная проверка установщика

Дата: 4 ноября 2026 года. Нативная сборка: `4e8e3ce0017891bf1549aa94272dc0142d0da6aa`, протокол 23.

| Проверка | Android API 35, телефон с root | Android API 37, без root |

| Упаковка синтетического APK, сохранение исходника и правильный повторный патч | PASS | PASS |
| Отказ перезаписи выходного файла и неверного ELF | PASS | PASS |
| Чтение метаданных базового и split APK | PASS | PASS |
| Создание и повторное использование ключа Android Keystore | PASS | PASS |
| Подпись и проверка APK на самом телефоне | PASS | PASS |
| Полная подготовка реальных игровых APK | PASS | PASS |
| Блокировка замены игры с другим сертификатом | PASS | PASS |

| Обновление только базового APK с наследованием ресурса | PASS | PASS |
| Совпадение SHA256 ресурсного split после обновления | PASS | PASS |
| Сохранение приватного файла данных тестового приложения | PASS | PASS |
| Запуск обычного установщика без instrumentation | PASS | PASS |

Root для операций установщика и его тестов подготовки не использовался: они
выполнялись с обычным UID приложения на обоих телефонах. Тесты системной установки
синтетического пакета используют привилегии instrumentation, чтобы не требовать
ручного подтверждения каждого теста. Они не заменяют проверку пользовательского
диалога установки настоящей игры.

На каждом телефоне подготовлены два APK общей длиной 2 233 007 166 байт. Это
локальные файлы собственной игры тестировщика, они не входят в репозиторий или
APK установщика. Базовый APK, созданный на нон-руте, дополнительно проверен на ПК
через SDK apksigner и `zipalign -c -P 16 4`: подпись и выравнивание корректны,
SHA256 вложенной библиотеки совпадает с нативной демосборкой.

На прошивке второго телефона фоновая instrumentation была приостановлена и
завершена механизмом энергосбережения. Тесты запускают экран установщика.
Тестовое приложение после свежей установки явно запускается перед чтением его
провайдера данных. Полный тест после этих поправок прошёл.

## Что пока не подтверждено

- Обновление настоящей игры с локальным ключом установщика и проверка её миров
  после обновления. Сохранность данных тестового приложения подтверждена отдельно.
- В версии 0.1 нет резервного копирования миров; результаты добавленного в 0.2
  механизма через Shizuku приведены выше.
- Другие прошивки, версии игры и сценарии нехватки места под большим реальным
  пакетом. Проверка свободного места есть, принудительный тест заполненного
  накопителя не проводился.

## Проверка настоящей игры после первой установки

4 ноября выполнена отдельная проверка с разрешения владельца телефонов:

- Перед изменениями сохранения обоих устройств скопированы на внешний накопитель.
  SHA256 каждого файла совпал до копирования, внутри архива и после копирования:
  25 файлов на хосте, 64 на госте. Отдельно сохранены приватные настройки хоста.
- На телефоне API 35 старая игра удалена. Подготовленный комплект установлен
  обычным приложением SN Multiplayer Installer через системный экран Android.
  PackageInstaller сообщил об успешной установке; источником пакета указан
  установщик проекта. SHA256 обоих установленных APK совпал с планом подготовки.
- Миры и настройки хоста восстановлены через ADB/root. SHA256 всех восстановленных
  файлов проверен; права назначены новому UID игры. Это отдельная процедура
  тестировщика, а не функция установщика.
- На телефоне без root выполнено совместимое обновление только базового APK
  через ADB с прежним сертификатом. Игра не удалялась, ресурсный split сохранён,
  все 64 файла сохранений перед запуском совпали с резервной копией. Этот шаг
  не считается проверкой обновления настоящей игры локальным ключом установщика.
- Unity запущена на обоих телефонах. Хост открыл восстановленный мир, гость получил
  869 119 байт в пяти файлах, включая архив ячеек. Проверка файлов и фиксация слота
  завершились. Автозагрузка гостя сообщила о завершении и снятии экрана загрузки.
- Парные снимки показали обоих игроков внутри общей базы. Логи обоих устройств
  подтвердили активного локального игрока, одного соседа и обмен состояниями.

Чистая установка и общая сессия подтверждены для этой пары устройств. Проверка
на телефоне с root не доказывает прохождение обычного диалога установки игры на
всех прошивках без root; тестовая подготовка и синтетические сессии на втором
телефоне описаны отдельно выше.
