# Установщик прямо на Android

**SN Multiplayer Installer 0.1.0-preview** — отдельное приложение, которое добавляет
мод к установленной на вашем телефоне копии Subnautica. Компьютер и root для его
работы не требуются. Приложение не содержит игру и не скачивает её.

**[Скачать APK установщика — около 1,6 МБ](https://github.com/zerk235/subnautica-android-multiplayer/releases/download/v0.1.0-installer-preview/snmp-installer-preview.apk)** · [Релиз и SHA256SUMS.txt](https://github.com/zerk235/subnautica-android-multiplayer/releases/tag/v0.1.0-installer-preview)

Скачивайте `snmp-installer-preview.apk` из **Assets** релиза. Архивы **Source code**
содержат исходники для разработчиков; устанавливать их на телефон не нужно.

Статус: предварительная сборка. Подготовка реальных APK проверена на двух
телефонах, включая телефон без root. На телефоне с root выполнена чистая установка
через обычный экран Android, запуск Unity и общая сессия со вторым телефоном.
Сам установщик работал с обычным UID; root и компьютер использовались отдельно
для резервной копии и восстановления миров тестировщика. Установщик пока не
решает перенос сохранений при первой смене подписи. Подробности — в
[протоколе проверок](INSTALLER_VALIDATION.md).

## Что нужно

- Android 10 / API 29 или новее, ARM64. Проверка на двух устройствах не означает
  поддержку любой прошивки.
- Собственная установленная Subnautica **1.22.83315** со всеми её ресурсами.
- Свободное место: при первой подготовке нужен полный новый комплект APK и
  временное место для самого большого пакета; при установке Android понадобится
  дополнительное место для своей сессии. Приложение проверяет доступный объём.
- Проверенная резервная копия миров перед изменением игровой установки.
  Если старые миры не нужны, можно выполнить чистую установку с потерей старого
  прогресса. Если они нужны, без проверенной копии не переходите к удалению игры.

## Что именно делает кнопка «Подготовить мод»

Это создание отдельного комплекта для будущей установки. Приложение берёт
файлы уже установленной Subnautica, записывает подготовленную копию в **свою
приватную папку**, добавляет мод, подписывает и проверяет результат.

| Данные или действие | Что происходит при подготовке |
| --- | --- |
| Основной APK игры | Создаётся отдельный APK с модом |
| APK с ресурсами игры | При первой смене подписи копируются и подписываются вместе с основным APK |
| Уже установленная игра | Остаётся установленной; подготовка её не заменяет и не удаляет |
| Миры, прогресс и настройки | Не копируются и не входят в подготовленный комплект |
| Установка результата | Выполняется позже отдельной кнопкой и через системный экран Android |

Например, на тестовых телефонах игра состоит из основного APK около 48 МБ и
ресурсного APK около 2,19 ГБ. При первой установке с другим ключом нужен весь
комплект. Гигабайтные файлы обрабатываются потоком; они не загружаются целиком
в оперативную память. Для этого комплекта первая подготовка требует примерно
5 ГБ свободного места с учётом временных файлов; приложение проверяет объём.

**Почему после этого можно удалить игру:** копия APK находится внутри другого
приложения — **SN Multiplayer Installer**. Удаление Subnautica не удаляет папку
установщика. Затем он устанавливает игру заново из своего подготовленного
комплекта. Это сохраняет установочные файлы, **но не ваши миры**.

**Дождитесь сообщения «Файлы готовы»**, прежде чем удалять игру. Сообщение
«Подпись установленной игры отличается» после успешной подготовки ожидаемо при
первой смене ключа. Если подготовка завершилась ошибкой, игру не удаляйте.

## Подготовка

1. Скачайте APK по ссылке выше и откройте его на телефоне. Если Android запросит
   разрешение установки для браузера или файлового менеджера, разрешите её
   приложению, которым открываете APK. Установите **SN Multiplayer Installer**.
2. Сохраните игру и выйдите в её главное меню.
3. Откройте **SN Multiplayer Installer**, проверьте найденную версию игры.
4. Нажмите **«Подготовить мод»**. На этом шаге игра и миры не меняются. Не
   закрывайте приложение принудительно; подготовка ресурсов может занять
   несколько минут, особенно на медленном накопителе.

Приложение читает базовый APK и необходимые split APK установленной игры,
добавляет нативный мод, выравнивает несжатые библиотеки на 16 КиБ, подписывает
локальным ключом и проверяет результат. Файлы остаются в приватной папке
установщика. Гигабайтные ресурсы обрабатываются потоком, а не целиком в памяти.

## Если подпись совпадает

После первой установки через этот же установщик последующие сборки используют
тот же локальный ключ. Для обновления подготавливается только базовый APK.
Установка использует режим наследования существующих split APK: ресурсы не
нужно заново переподписывать или передавать. Системный установщик запрашивает
подтверждение пользователя. Сохранения не удаляются намеренно; резервная копия
перед тестом всё равно нужна.

## Если подпись отличается

Оригинальная игра и старые сторонние сборки обычно подписаны другим ключом.
Android не разрешит установить поверх них новый APK с нашим локальным ключом.
В этом случае установщик подготавливает **весь комплект**, но блокирует замену
существующей игры.

Не удаляйте игру до завершения подготовки и проверки резервной копии нужных миров.
Удаление игры может удалить её сохранения. Установщик не умеет автоматически
копировать миры из чужой защищённой папки и не подтверждает сохранность вашей
ручной копии. Если надёжной копии нет и старый прогресс нужен, остановитесь на этом шаге.

Если вы решили выполнить первую чистую установку и сохранили нужные миры отдельно
либо согласны потерять старый прогресс:

1. Зажмите значок **Subnautica** на рабочем столе → **«Удалить»**. Другой путь:
   **Настройки Android → Приложения → Subnautica → Удалить**. Названия пунктов
   зависят от оболочки. Удаляйте именно игру, а не SN Multiplayer Installer.
2. Вернитесь в **SN Multiplayer Installer**. Подготовленный комплект остаётся
   в нём; повторная подготовка после удаления игры не требуется.
3. Нажмите **«Установить подготовленный мод»**. При запросе Android включите
   **«Разрешить установку из этого источника»** для **SN Multiplayer Installer**.
4. Вернитесь в установщик и снова нажмите установку, подтвердите его запрос,
   затем системный диалог Android. Дождитесь сообщения **«Мод установлен»**.
5. Нажмите **«Открыть игру»**.

Сам установщик игру не удаляет. Ранее сохранённые миры он автоматически не
восстанавливает. Для входа гостем в мир друга не нужно заранее копировать его
сохранение: мод получит его с телефона хоста при подключении.

## Остальные кнопки

| Кнопка | Что делает |
| --- | --- |
| «Установить подготовленный мод» | Передаёт проверенные APK системному установщику Android; при несовпадающей подписи установленной игры блокируется |
| «Открыть игру» | Запускает установленную Subnautica |
| «Отменить ожидающую установку Android» | Отменяет незавершённую сессию установки этого приложения; подготовленные файлы остаются |
| «Скопировать отчёт» | Копирует сведения о версии и текущем состоянии в буфер обмена для сообщения об ошибке |

## Локальный ключ обновлений

Ключ создаётся Android Keystore на конкретном телефоне и не экспортируется.
Не удаляйте установщик и не очищайте его данные: потеря ключа лишит его
возможности обновлять уже установленную игру тем же сертификатом. Для
обновлений самого установщика ставьте новую официальную сборку поверх старой.

На двух телефонах ключи могут отличаться. Для сетевой сессии должны совпадать
игра и нативная сборка мода, а не сертификаты APK.

## После установки

Запустите игру. На обоих телефонах используйте одну сборку мода и одну локальную
сеть. Хост открывает и сохраняет мир, гость остаётся в главном меню и ждёт
автоматической передачи. См. [инструкцию подключения](PLAYING.md).

Если системное подтверждение зависло или было закрыто, вернитесь в установщик.
Кнопка отмены ожидающей установки завершает только сессию этого приложения;
готовые файлы остаются. При ошибке скопируйте отчёт и приложите его к Issue,
предварительно проверив личные данные. Ключи и игровые APK не отправляйте.

## Для разработчика

Без Gradle и загрузки зависимостей при сборке:

```sh
python tools/build_installer.py --sdk /path/to/android-sdk --java-home /path/to/jdk
```

Перед этим соберите актуальный мод через `tools/build.py`. Используются
SDK Build Tools `35.0.0`, платформа `android-29`, JDK 17. apksig берётся из
установленных Build Tools; в APK включается библиотечная часть и уведомления
о лицензиях, а не утилиты SDK целиком. Ключей в исходниках нет.

Для подписанного APK передайте `--keystore /private/path/key.jks --alias ALIAS`.
Пароль запрашивается интерактивно. Выход: `build/installer/`.

Тестовая сборка:

```sh
python tools/build_installer.py --sdk /path/to/android-sdk --java-home /path/to/jdk --test --keystore /private/path/key.jks --alias ALIAS
adb -s YOUR_SERIAL install -r build/installer-test/snmp-installer-test.apk
adb -s YOUR_SERIAL shell am instrument -w -e mode sessions io.github.zerk235.snmp.installer/.InstallerTests
```

`sessions` устанавливает и обновляет только синтетический пакет
`io.github.zerk235.snmp.fixture`, проверяет сохранность split APK и приватного
файла данных. Тестовый пакет не содержит игру. `prepare-game` выполняет полную
подготовку реальных игровых APK и проверку подписей, но не устанавливает и не
удаляет игру. Для обычных тестов `-e mode ...` можно опустить.

Тестовые APK с instrumentation не распространять. В обычной сборке нет тестовых
компонентов и синтетических APK. Окончание команды `am instrument` с кодом shell 0
само по себе не означает успех: нужен `INSTRUMENTATION_CODE: -1` и строка `PASS`.

Использованные API: [PackageInstaller](https://developer.android.com/reference/android/content/pm/PackageInstaller),
[Android Keystore](https://developer.android.com/reference/android/security/keystore/KeyGenParameterSpec),
[apksig](https://android.googlesource.com/platform/tools/apksig/+/refs/heads/main/README.md),
[выравнивание APK](https://developer.android.com/tools/zipalign).
