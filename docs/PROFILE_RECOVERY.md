# Игра не найдена в текущем профиле Android

Входит в установщик 0.3.2.

На тестовом телефоне пакет Subnautica оставался установленным в профиле-клоне, но
основной профиль отмечался Android как `installed=false`. Сам факт наличия APK на
телефоне не означает, что игру можно запустить в основном профиле. Причина исходного
удаления из основного профиля пока не установлена.

В таком состоянии установщик предлагает «Вернуть игру в текущий профиль».
С разрешением Shizuku выполняется регистрация уже существующего пакета только для
профиля, где запущен установщик. APK сохраняет прежнюю подпись. Клон, другие профили
и их миры не удаляются. Если игра уже установлена в текущем профиле, операция
отклоняется до вызова системной команды.

Это возвращает приложение, но не восстанавливает удалённые сохранения. После
регистрации нужно восстановить проверенную копию через «Восстановить миры»; при
наличии такой копии установщик блокирует запуск до восстановления. Если Android сам
вернул старые файлы из облачной копии, восстановление ZIP сохраняет прежнюю папку
отдельно перед заменой.

При смене подписи игра в другом профиле вызывает конфликт: Android использует
единый установленный пакет для профилей. Поэтому подготовка замены при доступном
Shizuku заранее проверяет профили. Кнопка удаления требует подходящей версии,
полного подготовленного комплекта, проверенной копии и подтверждения отсутствия
игры в других профилях. Неизвестный результат проверки не разрешает удаление.
Перед системным запросом сверяются текущая установка и одноразовый результат
проверки с коротким сроком действия. Проверка профилей повторяется службой при
окончательной сверке сохранений. Действия вне установщика и изменения системы
после показа её окна удаления не контролируются установщиком.

После ответа Android об успешной установке дополнительно проверяются доступность
игры в текущем профиле, возможность запуска, версия, сертификат и SHA256
установленной библиотеки мода. Только после этого показывается сообщение об успехе.
Ошибка этой проверки записывается в диагностический журнал.

Не очищайте данные установщика: там находятся ключ подписи и копии миров. Не
удаляйте клон для обхода конфликта — сначала сохраните его миры и обратитесь к
разработчику с диагностическим ZIP.

Проверки на двух телефонах: подтверждены текущие профили, установленный сертификат,
версия и SHA256 библиотеки; отклонены неверный сертификат и попытка повторной
регистрации уже установленной игры. На телефоне без root реальный профиль-клон и
отличающийся ключ остановили подготовку до изменения прежнего комплекта APK.
Пять немедленных подключений к Shizuku подряд прошли на каждом телефоне после
устранения гонки закрытия службы: клиент отсоединяется, не запрашивая её принудительное
завершение перед следующим подключением. Восстановление 82 файлов миров через
рабочий сервис завершилось с совпадением SHA256 и сохранением предыдущей папки.
Возврат отсутствующей игры системной командой проверен на телефоне; положительный
сценарий новой кнопки ещё не проверялся повторным удалением настоящей игры.
