# Выбор хоста на телефоне

Доступно в установщике **0.3.0-preview**. [Скачать APK](https://github.com/zerk235/subnautica-android-multiplayer/releases/download/v0.3.0-installer-preview/snmp-installer-preview.apk).
Root и Shizuku для выбора роли не нужны.

1. Сохраните текущую игру, дождитесь окончания сохранения и выйдите в главное меню на обоих телефонах.
2. На будущем хосте откройте SN Multiplayer Installer → **«Запустить хостом»** и подтвердите запуск. В игре загрузите мир, которым хотите поделиться. Подойдёт и сохранение, ранее полученное от другого хоста.
3. На втором телефоне выберите **«Подключиться гостем»**, подтвердите запуск и оставьте игру в главном меню. Мод получит сохранение и загрузит его автоматически.

Оба телефона должны использовать одну сборку мода и одну локальную сеть. Для этой проверки оставьте только одного активного хоста.

Роль запоминается для следующих запусков игры. Чтобы поменяться ролями, снова сохранитесь, выйдите в главное меню на обоих телефонах и выберите нужные кнопки. Запрос, отправленный во время игры, дождётся главного меню.

Если у бывшего хоста есть отличающийся локальный мир с тем же именем папки, явный выбор гостя позволяет принять мир нового хоста после сохранения прежней папки отдельно. Следующие обновления гостевой копии не удаляют эту резервную папку. Перед тестами всё равно создавайте собственную проверенную копию миров через установщик.

**«Открыть игру автоматически»** возвращает прежний автоматический выбор: собственный загруженный мир может стать хостом; полученная гостевая копия сама хостом не становится.
