# Совместимость и состояние проверок

Состояние на 14 ноября 2026 года, установщик 0.3.10-preview. Игровые проверки проведены на двух Android ARM64-телефонах: один с root, другой без root. Это не подтверждение работы на любом устройстве. Игра: `1.22.83315`, Unity `6000.0.44f1`.

## Проверено в игре

| Возможность | Проверенный сценарий / условие |
| --- | --- |
| Первый перенос сохранённого мира | Гость получил мир, включая CellsCache, без копирования сохранения через компьютер |
| Новый мир хоста | Получение и автоматическая загрузка нового слота после исправления устаревшего контекста |
| Автоджоин | Вход из меню, повторный вход после перезапуска гостя |
| Выбор хоста | Нон-рут выбран хостом в установщике, загружен ранее полученный мир; второй телефон вошёл автоматически как гость |
| Фонарь | Удалённый свет включается, выключается и гаснет при убирании фонаря; пользователь подтвердил |
| Коридоры | Прямой, L, T, X, стеклянный прямой и стеклянный L: постройка, стыковка, демонтаж |
| Новый отдельный прямой отсек | В 0.3.2 подтверждены по логам два цикла постройки и полного демонтажа, включая удаление последней детали базы |
| Люки | На общих отсеках и многоцелевой комнате: постройка, проход, демонтаж |
| Окна и укрепления | Постройка и демонтаж на общей базе; пользователь подтвердил итоговую работу |
| Вертикальный соединитель | Постройка и демонтаж над общим обычным отсеком |
| Фундамент | Новый отдельный фундамент, пристройки с противоположных сторон, полный демонтаж и повторная постройка |
| Лестница | Постройка, проход, демонтаж и повторный цикл в том же месте |
| Многоцелевая комната | Пристройка к общей базе и новая отдельная комната; постройка и демонтаж пристыкованных к ней отсеков |
| Стеклянный купол комнаты | Постройка, демонтаж и повторный цикл; крыша восстанавливается снаружи и изнутри |
| Солнечная панель | Постройка и демонтаж на общей базе в обе стороны; PowerSource подключён. Выработка и общий баланс энергии не подтверждены |
| Биореактор | Постройка, удаление и повторный цикл на общей базе в обе стороны. Подтверждены загрузка топлива от хоста и от гостя без root и удаление из обеих копий предмета, израсходованного хостом. Общий баланс энергии отдельно не проверялся |
| Изготовитель | Постройка, меню, штатный локальный крафт и разбор в обе стороны; общая очередь крафта не передаётся. Поправка разбора после крафта проверена: меню закрыто, корпус раскрыт, удаление применено |
| Занятый «Мотылёк» | Проверен отказ гостю во входе в сетевую копию при уже управляющем напарнике; все варианты выхода и одновременная посадка ещё не проверены |
| Напольный шкаф (Locker 1504) | Хост → гость проверен в 0.3.3; в 0.3.4 проверены два цикла гость → хост, шкаф из сохранения после полного перезапуска и шкаф в новой отдельной комнате; в 0.3.5 добавлено общее содержимое, см. следующую строку |
| Содержимое напольного шкафа | Переносы титана и кварца в обе стороны, точное количество, заряд батарейки 57% → 57%, три ресурса после сохранения и полного перезапуска обеих игр |
| Аватар | Видимая голова, освещение внутри базы ночью, исправленный хват строителя |
| Метка напарника | Собственная иконка игрока в штатном HUD (0.3.7), видимость на обоих телефонах; создание, выключение и повторное создание без вылета |

Таблица относится к перечисленным действиям, а не к полной симуляции содержимого базы, прочности, затопления, энергии и всех связанных систем.

## Пока не заявляем поддержку

| Область | Состояние |
| --- | --- |
| Все варианты отдельной новой базы | Фундаменты, многоцелевая комната и пристройки к ним проверены в нескольких циклах; ещё не проверены все игровые типы и ситуации |
| Полное покрытие содержимого шкафа | Название, прямой перенос между шкафами, обмен при заполненной сетке и автоматическое восстановление переноса после сбоя процесса не реализованы; все инструменты, еда и обрывы во время переноса ещё проверяются |
| Все оставшиеся строительные объекты | Расширяются постепенно, полного покрытия нет |
| Рыбы и экосистема | Синхронизация не реализована |
| Все предметы и анимации | Не завершено; положение глайдера требует исправления |
| Транспорт, инвентарь и прочие игровые системы | Код отдельных механизмов присутствует; полная приёмка текущей демоверсии не проведена |
| Смена мира без перезапуска игры | Автоматические проверки есть, полный игровой сценарий ещё не подтверждён |
| Интернет и более двух игроков | Не проверено / не входит в текущую цель демо |
| Другие версии игры | Совместимость не подтверждена; мод зависит от конкретного IL2CPP API |

## Текущая сборка

Нативная сборка `80c65bbb2845608def875fc07b154ff69c799241`, протокол **33**.
[Обновление 0.3.10](releases/0.3.10-installer-preview.md) · [Обновление 0.3.9](releases/0.3.9-installer-preview.md) · [Обновление 0.3.8](releases/0.3.8-installer-preview.md) · [Панель](SOLAR_PANEL.md) · [Изготовитель и поправка разбора](FABRICATOR_SYNC.md).
На обоих телефонах прошли ARM64-проверки изготовителя, общего реестра, восстановления аватара, записи указателей, занятости транспорта и управления меткой.
Новая иконка игрока подтверждена пользователем и чтением назначенного спрайта; парные игровые снимки нового силуэта ещё не собраны. В 0.3.6 парными снимками была проверена прежняя иконка транспорта.
[Обновление 0.3.6](releases/0.3.6-installer-preview.md).
В 0.3.5 на обоих телефонах прошли ARM64-тесты содержимого шкафа, UDP-восстановления событий
и реестра. Игровые проверки и оставшиеся ограничения описаны в [0.3.5](releases/0.3.5-installer-preview.md).
В 0.3.4 на обоих телефонах прошёл ARM64-тест реестра с 2048 идентификаторами,
удалениями и запоздалыми сообщениями. Это проверка кода реестра; 2048 шкафов в игре
не строились. Отдельно на 0.3.4 подтверждены игровые циклы гость → хост, демонтаж
шкафа после загрузки сохранения и размещение/разбор в новой отдельной комнате.
Подтверждены передача мира, автоматический вход и смена ролей с нон-рутом в роли
хоста. Логи показывают завершение штатной загрузки и обмен состоянием между
двумя игроками. Небольшой переданный мир содержал три файла CellsCache.
Полный предел 96 МиБ в игровом тесте не проверялся.

В предыдущем тесте первого переноса и в проверке старого мира контрольные суммы
всех семи сохранённых файлов совпали между хостом и гостем. Для нового мира
подтверждены проверка передачи и загрузка; равенство более поздних снимков после
игры не заявляется.

Оба игрока должны использовать одну совместимую сборку мода. Прежние публичные
протоколы 31 и ниже несовместимы с протоколом 33. При обновлении нужно обновить
не только установщик, но и мод в игре на обоих телефонах. Обновление самого
установщика не перезапускает игру.
