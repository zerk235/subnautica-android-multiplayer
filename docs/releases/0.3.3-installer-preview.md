# SN Multiplayer Installer 0.3.3-preview

Download **snmp-installer-preview.apk** from Assets. Source archives contain
the mod and installer code, not a copy of Subnautica or a prepatched game APK.

## Changes

- Protocol 27 carries the exact parent-base identity and local transform for a
  new floor Locker (TechType 1504).
- The host-to-guest test confirmed construction in a shared base, matching
  placement and rotation, a usable empty storage, demolition, and rebuilding.
- Locker contents and names are not synchronized. Keep the test locker empty.
- New standalone foundations and supported base attachments now retain their
  identities and placements as the base grows and is dismantled.
- The Android installer version is 0.3.3-preview. Both players must prepare and
  install the same mod build; the previous public protocol 25 is incompatible.

## Verification

Thirteen native ARM64 checks passed on each of the two test phones, including
the real UDP event codec, locker payload validation, construction/deconstruction
triggers, base-anchor changes, and existing base-piece regressions. In game, a
new empty locker built by the host appeared at the correct place on the guest,
opened with storage ready, was removed, and was rebuilt. The user confirmed the
repeat removal and that the object did not return. The mod update was installed
over the existing game; save-file hashes and the resource APK were unchanged.

Game: Subnautica 1.22.83315 on two ARM64 Android phones. The reverse guest-to-host
locker direction and lockers already present in a save were not tested. This is
an experimental LAN demo, not a complete multiplayer simulation.

## Install the update

1. Install the new installer APK over the existing SN Multiplayer Installer;
   keep its data and signing key.
2. Save the game on both phones and return to the main menu.
3. In the installer, prepare and install the updated mod on both phones.
4. Start the host, load the shared world, and let the guest join.

Do not uninstall the game manually to work around a signature or clone warning.
See the [installer guide](../INSTALLER.md), [locker details](../LOCKER_SYNC.md),
and [compatibility table](../COMPATIBILITY.md).

SHA256 checksums for the release assets are attached as **SHA256SUMS.txt**.
