# 0.3.8-preview — новый интерфейс установщика

Предварительная публичная демоверсия для двух игроков по локальной сети.
Нативная сборка мода и протокол не изменились: **28dc3ee3cdeeaf183758adaed69703d257446605**, протокол **31**.

## Что изменилось

- Установщик получил новый тёмно-бирюзовый интерфейс: карточки, пилюли-кнопки,
  чипы статуса и шаговые бейджи вместо прежнего списка.
- Нижняя навигация с четырьмя вкладками: **Главная**, **Установка**, **Миры**,
  **Настройки**. Переключение мгновенное, состояние сохраняется при возврате.
- На вкладке «Установка» — пять шагов с индикаторами и прогресс-полосой;
  «Миры» — резервные копии и перенос; «Настройки» — информация о сборке и
  диагностика.
- Исправлены падения интерфейса: переключение вкладок, возврат игры в текущий
  профиль и пустой экран из-за наложения экранов.
- Сборка подписывается без интерактивного запроса пароля: пароль читается из
  переменной окружения `SNMP_INSTALLER_SIGN_PASS`.

## Проверки

- Установка и запуск на realme/OPPO, Android 11+, ARM64.
- Все четыре вкладки открываются без краха; переключение выполнено в обе стороны.
- Статус мода и версии игры/протокола отображаются на главной и в настройках.
- Проверена сборка `28dc3ee3cdee…`, протокол 31; игра **1.22.83315**.

## Как обновиться

1. Установите **snmp-installer-preview.apk** из Assets поверх прежнего установщика.
   Сохраните данные приложения: в них находится ваш ключ обновлений.
2. Интерфейс обновляется сразу. Мод в игре и протокол те же, поэтому заново
   выполнять «Подготовить мод» не требуется.
3. Если ранее был прерван перенос мира, используйте проверенную копию миров.
