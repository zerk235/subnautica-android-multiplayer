# Установщик 0.3.0-preview

Предварительное демо с выбором хоста на телефоне. В Assets скачивайте **snmp-installer-preview.apk**; **Source code** — исходники, не приложение для Android.

## Обновление с 0.2

Установите новый APK **поверх SN Multiplayer Installer**, сохранив данные приложения и его ключ. На обоих телефонах сохраните игру, дождитесь окончания сохранения и выйдите в главное меню, затем выполните **«Подготовить мод» → «Установить подготовленный мод»**. При совместимой подписи игра обновляется без удаления; ресурсы наследуются от установленной игры.

Если Android сообщает о другой подписи или игра находится в другом профиле, следуйте [инструкции копирования миров](../INSTALLER_BACKUPS.md). Не удаляйте другие профили или миры для обхода ошибки подписи. Выбор роли выполняется после установки совместимой сборки мода.

**Обновиться должны оба игрока:** протокол 25 несовместим с прежней публичной сборкой протокола 23.

## Выбор хоста

В верхней части установщика появились **«Запустить хостом»** и **«Подключиться гостем»**. Для выбора роли root и Shizuku не нужны. Роль запоминается; её изменение применяется в главном меню, без прерывания открытого мира.

Хостом можно сделать телефон без root, в том числе используя мир, ранее полученный от другого хоста. При явном переходе бывшего хоста в гости исходная папка его мира сохраняется отдельно. Эта резервная версия переживает последующие обновления гостевой копии.

Исправлен автоматический вход при смене ролей: если файлы мира уже совпадают с копией нового хоста, бывший хост всё равно получает корректную гостевую копию с сохранением исходной папки. Раньше проверка совпадения пропускала этот шаг, и автоматическая загрузка останавливалась.

Подробные шаги — в [инструкции выбора хоста](../HOST_SELECTION.md).

## Установщик

- Устаревший подготовленный APK больше не блокирует запуск установленной игры и выбор роли. Для его установки по-прежнему требуется повторная подготовка.
- Экран обновляет текст только при изменениях; фокус больше не перемещает страницу к сообщению состояния.
- Проверенные копии миров и восстановление через Shizuku сохранены. Кнопки выбора роли не выполняют подготовку, удаление или переустановку игры.

## Совместимость и проверка

Сборка мода: `6e7da9662722914643d326178d3e35a2018a87f7`, протокол **25**. Для совместной игры нужна эта совместимая сборка на обоих телефонах; публичная сборка протокола 23 с ней несовместима.

На двух телефонах подтверждён обмен ролями: телефон без root загрузил мир как хост, второй получил его автоматически как гость. В логах подтверждены завершение штатной загрузки и обмен игровым состоянием. Автоматические проверки также покрывают сохранение исходной папки мира при совпадающих и отличающихся файлах.

Это предварительное демо. Удаление последней детали новой отдельной базы ещё не исправлено; положение глайдера не завершено. Для совместного строительства используйте поддерживаемые детали существующей общей базы и отдельный тестовый мир. Полная синхронизация всех объектов игры не заявляется.
