# Установщик 0.3.2-preview — демонтаж базы и повторное подключение

Скачивайте **snmp-installer-preview.apk** из Assets. Архивы Source code содержат
исходники, а не приложение для телефона. Игра и готовый APK игры не распространяются.

## Как обновиться

1. Установите новый APK **поверх прежнего SN Multiplayer Installer**. Не очищайте
   его данные: там находятся ключ обновлений и копии миров.
2. На обоих телефонах сохранитесь и выйдите в главное меню игры.
3. На каждом телефоне выполните **«Подготовить мод» → «Установить подготовленный мод»**.
   Игра, ранее установленная тем же локальным ключом, обновляется без удаления.
4. На одном выберите «Запустить хостом» и загрузите мир; на другом — «Подключиться
   гостем» и оставьте главное меню для автоматического входа.

**Одного обновления установщика недостаточно:** игровая библиотека изменилась.
Нативная сборка: `8e370d84e0de841a1cfa34bae3148b2f7561c3a7`, протокол **25**.
У обоих игроков должны совпадать сборки игры и мода.

## Исправления

- Демонтаж деталей базы: исправлена сигнатура игровой функции проверки пустой базы,
  из-за которой обработчик удаления вообще не включался.
- Новая база текущей сессии распознаётся по точному идентификатору, записи завершённой
  постройки и проверенной геометрии, даже если игровой флаг размещения не выставлен.
- Повторный вход: запоздавшее сообщение присутствия больше не стирает выданное хостом
  разрешение JOIN. Разрешение привязано к конкретным сессии и эпохе.
- Добавлены журналы отправки и получения положения игроков, причин блокировки и
  переходов состояния сессии для разбора исчезновения персонажа.
- При смене подписи патчер заранее проверяет конфликт с клоном / другим профилем.
  Удаление требует подходящего сценария замены и свежей проверки; любая ошибка
  установки сама по себе не разрешает удаление игры.
- Кнопка «Вернуть игру в текущий профиль» возвращает существующий APK с прежней
  подписью через Shizuku, сохраняя клон. После неё миры восстанавливаются отдельно
  из проверенной копии. Это не способ обойти конфликт разных ключей.
- Устранена гонка повторных подключений к службе Shizuku. После установки проверяются
  доступность игры в текущем профиле, версия, сертификат и SHA256 библиотеки мода.

## Что проверено

На двух телефонах прошли тесты поиска базы, разрешения методов демонтажа, удаления
отсеков/комнат/фундамента на моделируемом игровом API, сессий и диагностики потока
положения. В реальной игре при хосте без root прошли **два полных цикла постройки
и удаления нового отдельного прямого отсека**; гость подтвердил удаление каждой
пустой базы с `verified=1`. Подтверждён повторный автоматический вход после
сохранения и полного перезапуска. Сохранения и ресурсные APK не изменились при
совместимом обновлении игры на тестовых телефонах.

Проверены архивы миров, защита профилей, фактический конфликт ключа с клоном,
отказ до подготовки APK и пять подключений к Shizuku подряд на каждом телефоне.
Положительный сценарий новой кнопки возврата игры не проверялся повторным удалением
настоящей игры; возврат системной командой и восстановление миров проверены отдельно.

## Ограничения

Последний фундамент и все варианты комнат после этой поправки ещё требуют
отдельных игровых тестов. Исчезновение гостя через несколько минут в тесте с
другом не считается доказанно исправленным — для него нужны отчёты обоих телефонов.
Глайдер, все анимации, рыбы и полная симуляция экосистемы остаются незавершёнными.
Это экспериментальная LAN-демоверсия для двух ARM64-телефонов с игрой **1.22.83315**.

При конфликте профилей **не удаляйте игру вручную**. Если она отсутствует в текущем
профиле, но осталась в клоне, используйте возврат и восстановление копии миров.
