# Установщик 0.3.1-preview — диагностика

Скачивайте **snmp-installer-preview.apk** из Assets. Source code — исходники,
а не приложение для телефона.

## Обновление

Установите APK **поверх прежнего SN Multiplayer Installer**, сохранив данные.
Если игра уже использует мод из 0.3.0, переподготавливать и переустанавливать
её не нужно. Встроенный мод прежний: `6e7da9662722914643d326178d3e35a2018a87f7`,
протокол **25**. Эта версия не исправляет исчезновение игроков, удаление
последнего фундамента или положение глайдера.

## Что изменилось

- Понятные коды ошибок с объяснением, следующими действиями, этапом и стеком.
- Сохранение последней ошибки после перезапуска, включая Java-сбой самого установщика.
- Диагностический ZIP: описание игрока, версии и подписи, свободное место,
  Shizuku, признаки сети, история операций и ответы Android.
- Игровые журналы через Shizuku и недавний logcat только процесса Subnautica
  текущего профиля. Игра не останавливается и её файлы не меняются.
- SHA256 фактически установленного мода сравнивается с модом в установщике.
- Признак остановки пакетов положения при продолжающихся сообщениях присутствия
  отмечается с временем и исходными строками. Это признак, не доказанная причина.
- Отправка ZIP через меню Android и сохранение в выбранную папку с проверкой SHA256.
- Отчёт создаётся и при недоступном Shizuku; пропуски явно указаны. Внутри нет
  APK, миров, ключей подписи и журналов других приложений. Автоматической отправки нет.

## Как сообщить о проблеме

На каждом телефоне: **«Создать диагностический ZIP» → описание → «Отправить ZIP»**.
При сбое синхронизации соберите два отчёта примерно одновременно и укажите хоста.
Для игровых журналов запустите Shizuku и разрешите установщику доступ.
[Подробная инструкция и состав отчёта](../DIAGNOSTICS.md).

В журнале игры могут быть локальные IP, имена слотов и команды — учитывайте это
при публичном размещении. Время исходных файлов, обрезка и недоступные данные
записаны в отчёте. Он не заменяет резервную копию миров.
