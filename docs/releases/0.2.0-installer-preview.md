# Android Installer 0.2.0 — миры и помощь с Shizuku

Предварительное демо для собственной **Subnautica 1.22.83315**, Android ARM64.
В Assets скачайте **snmp-installer-preview.apk** и при необходимости проверьте
его по **SHA256SUMS.txt**. Игры и её ресурсов в APK установщика нет.

## Изменения

- Копирование SavedGames в отдельный ZIP через Shizuku, с SHA256 каждого файла
  и проверкой, что сохранения не изменились во время чтения.
- Восстановление через временную папку и финальную проверку; прежние миры
  остаются в резервной папке рядом. Приватные настройки игры не копируются.
- Экспорт ZIP в выбранную папку и импорт ранее сохранённого архива.
- Кнопка удаления старой игры открывает системный запрос только после проверки
  APK, целостности и актуальности копии, а также конфликтующих Android-профилей.
- Отслеживание удаления отдельно от подписи: восстановление необходимо и при
  повторном использовании прежнего сертификата.
- **«Помощь с Shizuku» прямо в приложении**, включая «Доступ к ADB ограничен»
  на realme GT8 V17: временный English → Developer options → Disable system
  optimization → подтверждение предупреждения → перезапуск Shizuku → доступ
  установщику. Русский можно вернуть. Возможен рост расхода батареи в фоне.

## Первая установка

На Android 11+ Shizuku можно запустить через беспроводную отладку на самом
телефоне без компьютера и root. Он устанавливается отдельно из официального
источника и требует вашего разрешения. Для подготовки APK он не нужен.

Сохранитесь и выйдите в меню игры. В установщике:

1. **Подключить Shizuku → Создать копию миров**.
2. **Подготовить мод** — APK копируются в отдельное приложение. При первой смене
   подписи и разрешённом Shizuku также создаётся свежая копия миров.
3. **Удалить старую игру → Проверить** — подтвердите отдельное окно Android.
4. **Установить подготовленный мод** — разрешите установку из этого приложения.
5. **Восстановить миры → Открыть игру** после подтверждённого восстановления.

Не удаляйте сам установщик и не очищайте его данные: в нём находятся APK,
копии миров и ключ будущих обновлений. Дополнительно экспортируйте ZIP наружу.
Если игра остаётся в другом профиле / клоне с прежней подписью, удаление
основной копии не решит конфликт. Установщик блокирует этот шаг заранее;
самостоятельно удалять другие профили и их миры не требуется.

## Проверки и границы демо

Копирование реальных миров проверено через Shizuku на руте (26 файлов) и без
root (64 файла, UID 2000). На телефоне без root миры восстановлены после удаления
основной игры пользователем, все 64 SHA256 независимо сверены. Существующий пакет
для основного профиля при ремонте телефона включался через ADB из сохранившейся
копии другого профиля; это не чистая установка APK новым ключом без компьютера.
Проверка отказа из-за профиля User 11 прошла на реальном телефоне.

Пройдены проверки повреждённого архива, путей, ссылок, импорта и сохранения
прежней папки миров. Полный непрерывный сценарий первой смены сертификата
APK+миры версии 0.2 без ADB отдельно ещё не завершён. Обновление настоящей игры
локальным ключом установщика тоже остаётся отдельным непроверенным сценарием.

Нативный мод не менялся: `4e8e3ce0017891bf1549aa94272dc0142d0da6aa`, протокол 23.
Демо рассчитано на двух игроков в одной локальной сети. Рыбы, все предметы и
анимации не синхронизируются полностью; первая отдельная база после подключения
гостя пока не поддерживается.
