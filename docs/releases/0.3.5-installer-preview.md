# 0.3.5-preview — общее содержимое напольного шкафа

В обычном напольном шкафу Locker теперь можно передавать предметы между хостом
и гостем. Хост подтверждает перенос конкретного предмета, а получатель
восстанавливает его штатные игровые данные, включая проверенный заряд батарейки.
Постройка и разбор шкафа из предыдущего выпуска сохранены.

## Проверено на двух телефонах

- Хост положил титан → гость забрал → гость вернул → хост забрал. Один и тот же
  игровой ID прошёл весь цикл; предмет не возвращался в пустой шкаф.
- Из 3 титанов и 1 кварца гость забрал один титан: на обоих осталось 2 титана и
  1 кварц. Проверены отдельные идентификаторы и подтверждения переносов.
- Батарейка передана с зарядом **57% → 57%**, по проверке пользователя.
- После дополнительных переносов хост сохранил шкаф с двумя титанами и кварцем.
  В файле мира найдены те же ID шкафа и трёх предметов. Обе игры полностью
  перезапущены: хост загрузил три предмета, гость подтвердил совпадающее содержимое
  по сетевому снимку; пользователь также подтвердил результат на экранах.
- На каждом телефоне прошли ARM64-тесты протокола содержимого, восстановления
  сетевых событий и реестра шкафов. В тестах кода проверены повторные запросы,
  конкуренция за один предмет, предел вместимости и повреждённые сообщения.
- Установщик показывает свою фактическую версию вместо старой фиксированной строки.

## Ограничения предварительной версии

Поддержан **обычный напольный Locker**, перенос между ним и личным инвентарём.
Настенные шкафы, название шкафа, прямой перенос между шкафами и обмен предметами
при заполненной сетке пока не поддержаны. Полная проверка всех инструментов,
еды, одновременного забора в игре и обрыва связи во время переноса ещё впереди.
Сохранение личного инвентаря гостя остаётся отдельным ограничением демо.

Перед удалённым переносом создаётся локальный журнал. Если процесс аварийно
закрылся посреди операции, журнал сохраняется и блокирует её автоматическое
повторение. **Автоматическое восстановление такого переноса ещё не реализовано.**
Не удаляйте журнал для обхода блокировки: создайте диагностический отчёт и
сообщите автору. Для первых проб используйте отдельный мир и обычные ресурсы.
Батарейка проверена при передаче; сохранение её заряда после перезапуска в этом
сценарии отдельно не проверялось.

## Как обновиться

1. Скачайте **snmp-installer-preview.apk** из Assets и установите поверх прежнего
   SN Multiplayer Installer. Сохраните данные приложения и его ключ обновлений.
2. Сохраните мир хоста, дождитесь окончания сохранения и выйдите в главное меню
   на обоих телефонах.
3. **На обоих телефонах** выполните **«Подготовить мод» → «Установить подготовленный мод»**.
   Обновления одного установщика недостаточно: изменился мод внутри игры.
4. Запустите хоста и загрузите мир; гостя оставьте для автоматического входа.

Игру вручную удалять не нужно. «Подготовить мод» создаёт и проверяет отдельную
подписанную копию APK; эта кнопка сама её не устанавливает и не удаляет игру.

Нативная сборка: `bcf06e6fdc220926bc5cff2f9efbd13c0c3e2203`, протокол **28**.
Оба игрока должны использовать одинаковую сборку; протокол 27 из 0.3.4 несовместим.
Игра: **1.22.83315**, Android 10+, ARM64. Установщик не содержит игру.
