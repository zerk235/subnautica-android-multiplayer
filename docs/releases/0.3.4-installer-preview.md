# Установщик 0.3.4-preview — реестр шкафов без предела в 64 записи

Скачивайте **snmp-installer-preview.apk** из Assets релиза. Рядом находится
**SHA256SUMS.txt**. Архивы Source code содержат исходники.

## Исправлено

- После 64 разных шкафов за сессию новые постройки переставали приниматься,
  даже если прежние шкафы уже разобраны. Фиксированный массив заменён растущим
  реестром с сохранением ссылок на записи.
- Записи удаления сохраняются до смены сессии. Позднее сообщение о постройке
  по-прежнему не возвращает разобранный шкаф. Простого вытеснения старых
  записей удаления нет.
- В README исправлены устаревшие инструкции про текущий протокол 25;
  актуальный протокол — **27**. Таблица совместимости теперь отражает
  проверенные новые многоцелевые комнаты, фундаменты и пристройки к ним.

## Проверки и ограничения

На каждом из двух Android ARM64-телефонов прошёл `test_interior_build`:
2048 идентификаторов, постройки и удаления, защита самых старых записей от
повторной постройки, стабильность ссылок при росте реестра, неизменность
родительской базы и положения, очистка при смене сессии.
Нативная библиотека собрана NDK 26.1 для ARM64 / Android API 29.

Это проверка кода реестра. Постройку 2048 шкафов в игре не проверяли.
Игровая приёмка постройки и демонтажа нового пустого шкафа хостом с
отображением у гостя относится к 0.3.3. Отдельный игровой тест 0.3.4,
постройка гостем, старые шкафы из сохранения и шкаф в новой комнате
остаются следующими проверками.

Содержимое и название шкафа пока не синхронизируются. Память реестра растёт
с количеством разных идентификаторов за сессию и освобождается при её смене.
При нехватке памяти отказ записывается в журнал.

## Обновление

1. Установите APK поверх прежнего **SN Multiplayer Installer**, сохранив данные.
2. На обоих телефонах сохранитесь и выйдите в главное меню игры.
3. Выполните **«Подготовить мод» → «Установить подготовленный мод»** на обоих.
4. Запустите хоста, загрузите мир; гостя оставьте для автоматического входа.

Нативная сборка: `dc275c08ecbf7a0276829ab0a003a839010aa714`, протокол **27**.
Оба игрока должны использовать одинаковую сборку. Одного обновления установщика
недостаточно — мод в игре тоже нужно обновить. Игру вручную не удаляйте.
