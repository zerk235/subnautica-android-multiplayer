# До первого публичного демо

## Подготовлено

- [x] Автоматическая передача поддерживаемого полного сохранения с хоста, включая CellsCache.
- [x] Автоматический вход гостя и проверка нового мира хоста.
- [x] Живые проверки основных перечисленных деталей общей базы.
- [x] Чистый экспорт исходников, описание ограничений и инструкции для тестеров.
- [x] Предварительный установщик Android: локальная подготовка и подпись реальных APK на root и non-root телефонах, блокировка конфликта сертификатов.

## Перед приглашением игроков

- [ ] Завершить полный игровой тест установщика: обычное подтверждение Android, установка игры и первый запуск без root.
- [ ] Собрать точный публичный артефакт и прогнать его на двух телефонах: первый перенос, повторный вход, строительство/демонтаж/повторная постройка.
- [ ] Проверить смену миров без перезапуска или явно оставить обход через перезапуск.
- [ ] Проверить сообщения о несовместимой версии, слишком большом сохранении и обрыве передачи.
- [ ] Подготовить инструкцию резервного копирования и восстановления для выбранного установщика.
- [ ] Оформить prerelease с версиями, контрольными суммами и известными проблемами. Не прикладывать файлы игры и ключи подписи.

## Следующие этапы

1. Создание первой отдельной базы во время общей сессии.
2. Остальные строительные объекты от простых к сложным.
3. Положение удерживаемых предметов, анимации и состояние света фонаря.
4. Отдельное исследование синхронизации рыб и существ.

Это план развития, а не обещание сроков или полноты игровой симуляции.
