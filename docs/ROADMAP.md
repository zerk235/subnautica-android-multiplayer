# Состояние предварительного демо и следующие шаги

## Подготовлено

- [x] Автоматическая передача поддерживаемого полного сохранения с хоста, включая CellsCache.
- [x] Автоматический вход гостя и проверка нового мира хоста.
- [x] Живые проверки основных перечисленных деталей общей базы.
- [x] Чистый экспорт исходников, описание ограничений и инструкции для тестеров.
- [x] Предварительный установщик Android: локальная подготовка и подпись реальных APK на root и non-root телефонах, блокировка конфликта сертификатов.
- [x] Чистая установка игры через обычный экран Android на телефоне с root, отдельное восстановление миров и общая сессия с гостем. Установщик работал с обычным UID; копирование миров выполнялось через ADB/root.
- [x] Пошаговая инструкция первой смены подписи и объяснение кнопок установщика. Автоматического резервного копирования миров пока нет.

## Оставшиеся проверки и доработки

- [ ] Повторить чистую установку самой игры и первый запуск на телефоне без root. Подготовка реальных APK и синтетические сессии на нём проверены.
- [ ] Проверить обновление настоящей игры локальным ключом установщика с сохранением миров.
- [ ] Повторить полный цикл строительства/демонтажа/повторной постройки на публичной упаковке. Общая сессия и перенос на ней проверены; игровые проверки строительства ранее проходили на совместимой нативной сборке.
- [ ] Проверить смену миров без перезапуска. В инструкции пока указан обход через перезапуск.
- [ ] Проверить сообщения о несовместимой версии, слишком большом сохранении и обрыве передачи.
- [ ] Добавить удобное резервное копирование и восстановление миров без компьютера и root перед первой сменой подписи.

## Следующие этапы

1. Создание первой отдельной базы во время общей сессии.
2. Остальные строительные объекты от простых к сложным.
3. Положение удерживаемых предметов, анимации и состояние света фонаря.
4. Отдельное исследование синхронизации рыб и существ.

Это план развития, а не обещание сроков или полноты игровой симуляции.
