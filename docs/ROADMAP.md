# Состояние предварительного демо и следующие шаги

## Подготовлено

- [x] Автоматическая передача поддерживаемого полного сохранения с хоста, включая CellsCache.
- [x] Автоматический вход гостя и проверка нового мира хоста.
- [x] Живые проверки основных перечисленных деталей общей базы.
- [x] Чистый экспорт исходников, описание ограничений и инструкции для тестеров.
- [x] Предварительный установщик Android: локальная подготовка и подпись реальных APK на root и non-root телефонах, блокировка конфликта сертификатов.
- [x] Чистая установка игры через обычный экран Android на телефоне с root, отдельное восстановление миров и общая сессия с гостем. Установщик работал с обычным UID; копирование миров выполнялось через ADB/root.
- [x] Пошаговая инструкция первой смены подписи, помощь с Shizuku в приложении и объяснение кнопок установщика.
- [x] Копия SavedGames с SHA256 через Shizuku на обоих телефонах; восстановление настоящих миров проверено на телефоне без root. Проверка конфликтующего профиля / клона перед удалением.
